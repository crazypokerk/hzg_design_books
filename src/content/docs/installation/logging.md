HAC 日志用于排查容器运行、设备能力调用、扫码、定位、拍摄、文件和兼容性问题。日常使用不建议长期打开详细日志，以免影响性能和占用存储。

## 日志位置

日志默认保存在设备 `Download` / `Downloads` 文件夹中。

![hac日志](../../../assets/logs_hac_2.png)

文件名通常类似：

```text
HAC_Log_ERROR_20240112.txt
```

日志按天拆分，默认保留最近 `7` 天。反馈问题时，优先收集问题发生当天的文件；跨天复现时同时收集相邻日期日志。

## 日志级别

| 级别 | 用途 |
| --- | --- |
| `error` | 默认级别，只记录错误和异常 |
| `verbose` | 诊断级别，记录更详细的运行过程 |

只有在配合排查问题时，才临时启用 `verbose`。

## 启用诊断日志

在 HAC 设置页勾选“启用全部诊断日志”。

![启用verbose日志](../../../assets/logs_hac_1.png)

:::caution[需要重启]
日志策略通常需要杀掉 HAC 进程后重新启动才会生效。问题排查结束后，应关闭诊断日志并再次重启 HAC。
:::

## 转存日志

可选方式：

- 设备文件管理器中打开 `Download` 文件夹，复制日志。
- 使用 USB 数据线传到电脑。
- 使用蓝牙、企业文件传输工具或内部工单附件上传。
- 在设备上用文本查看器直接打开。

## 问题反馈清单

提交给开发或支持人员时，建议同时提供：

- 问题发生时间。
- 复现步骤。
- 设备型号。
- Android 版本。
- WebView 版本。
- HAC 版本。
- 当天 HAC 日志。
- 如涉及页面异常，附 DevTools Console / Network 关键错误。

## 排查建议

| 现象 | 建议 |
| --- | --- |
| 页面按钮无响应 | 先看 DevTools `Console`，再看 HAC 日志中的本地能力调用异常 |
| 扫码结果没有写入 | 检查扫码广播配置、页面监听逻辑和 HAC 扫码日志 |
| 拍照、定位、文件失败 | 检查 Android 权限、命令返回值和 HAC 异常堆栈 |
| 只在某台 PDA 出现 | 对比设备型号、系统、WebView、HAC 版本和厂商配置 |

页面运行时调试请参考[调试](./debugging/)。
