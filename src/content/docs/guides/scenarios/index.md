## 文档结构

各功能页尽量按同一节奏组织：

1. 适用场景：先判断该能力是否该用。
2. 使用前提：确认 HAC、权限、设备和插件条件。
3. 命令速查：找到对应命令和返回结果。
4. 推荐流程：给出可直接照搬的页面编排。
5. 设计要点：明确状态、反馈、生命周期和误操作防护。
6. 异常处理：告诉现场用户下一步该做什么。
7. 验收标准：上线前逐项验证。

## 通用原则

- 现场操作优先：扫码、按键、NFC、BLE 等能力要围绕实际作业流程设计，不要只做成输入框。
- 状态必须可见：等待、成功、失败、已提交、待补传等状态要清楚。
- 生命周期要收口：持续扫码、广播监听、BLE 订阅、物理按键监听离开页面时必须停止。
- 配置和业务分开：ActionBar、扫描头参数等配置类命令放在运维或管理员页面。
- 异常给出恢复路径：重试、重新扫描、手动修正、联系管理员或转备用流程。
