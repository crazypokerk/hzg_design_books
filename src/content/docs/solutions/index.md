本部分以完整业务闭环为单位，说明现场角色、页面职责、HAC 能力、异常恢复和验收标准。它不重复功能命令的全部参数，而是展示这些能力如何组合。

## 当前案例

- [采购入库](./pda-inventory-counting/)：围绕 PO 选择、连续收货、扫码、离线暂存、异常恢复和数据同步设计 PDA 页面组。

## 阅读方法

1. 先确认角色、设备、网络和业务边界；
2. 再看页面如何组织任务、对象、数量和下一步操作；
3. 对照 HAC 功能页确认扫码、离线、拍摄或其他设备能力的配置；
4. 最后按验收标准在目标 PDA 和 HAC 中验证主流程与异常流程。

后续方案可以按巡检、资产盘点、门店收货、BLE 设备采集或拍照取证继续扩展。
